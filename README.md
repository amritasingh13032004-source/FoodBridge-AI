# FoodBridge AI

FoodBridge AI is an intelligent platform designed to reduce surplus food wastage by connecting food donors with suitable food-relief organizations.

## Main Objectives

- Food classification using AI
- Image-based freshness/spoilage risk estimation
- Approximate food quantity categorization
- Food rescue priority calculation
- Intelligent NGO matching
- Donation and pickup management
- Impact analytics

## Technology Stack

- Python
- TensorFlow/Keras
- OpenCV
- FastAPI
- MongoDB
- HTML
- CSS
- JavaScript
- Leaflet
